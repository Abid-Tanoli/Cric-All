# How to change the logo
Replace `logo-emblem.png` in this folder with your transparent PNG (keep the name).
Optional: replace `logo-full.png` too; delete it to fall back to the emblem.
Edit `brand.json` only for names/colours, then deploy both frontends.
Builds regenerate every icon, favicon, social image and in-app logo automatically.
No other file needs editing; keep the filenames and run the deploy as usual.
